# Word Guess — React + TypeScript

## Live demo

**[Open the interactive demo](https://saqif-word-guess.vercel.app/)** — no installation or sign-in required.

A small React and TypeScript word-guessing game. Use the on-screen keyboard or your keyboard to guess letters, then select New game for a fresh random word. No account or backend is required.

### Build the public demo

```sh
npm ci
npm run build
```

Static output: `dist/`. Deploy that directory to a static host. Demo deployments are snapshots and must be rebuilt and redeployed after source changes.
